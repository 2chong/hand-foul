라벨링 가이드

손 위치 반칙 분류 · v0.1 · 사진을 normal 폴더와 foul 폴더에 나눠 넣는 기준

1. 규칙

손이 마우스패드 빨간 테두리 안에 다 들어가 있으면 → normal
손의 어느 부분이라도 빨간 테두리 밖으로 나가 있으면 → foul
손목 아래 팔은 안 본다. 팔이 패드 밖으로 나가는 건 상관없음.

3. 애매한 경우

상황어디에 넣나
손가락 하나 끝만 빨간 선 넘어서 담요 위에 있음foul — 제일 중요한 케이스. 많이 찍을 것
손가락이 빨간 선 위에 딱 걸쳐 있고, 선 바깥 담요는 안 보임normal — 빨간 선까지는 안쪽으로 침
손바닥 끝(손목 쪽)이 패드 아래 변 밖으로 나감foul — 손바닥은 손
손목선은 패드 밖, 손바닥·손가락은 전부 안normal
주먹 쥐거나 손 오므린 채 패드 안normal — 모양 상관없음
손이 패드에 아예 없음foul
손이 두 개 찍힘안 씀 — 이번 버전은 손 하나만
흔들려서 손가락 끝이 안 보임 / 패드 테두리가 사진에 안 잡힘안 씀 — 삭제하거나 data/skip/에 치워둠
손이 공중에 떠 있는 것 같음위에서 본 위치 기준으로 판단. 정 애매하면 안 씀
소매나 시계가 손목을 가림보이는 손 부분으로 판단

원칙: 애매하면 억지로 넣지 말고 뺀다. 애매한 사진 한 장이 모델을 더 헷갈리게 한다.

4. 작업 방법

  • 찍은 사진을 전부 data/inbox/에 넣는다. 파일명은 겹치지만 않으면 됨.
  • hand-foul label 을 실행하면 창이 뜨고 사진이 한 장씩 크게 나온다. 1 normal · 2 foul · s 건너뛰기 · z 되돌리기 · q 종료. 누르면 파일이 해당 폴더로 옮겨진다.
  • 중간에 끄면 다음에 켰을 때 inbox에 남은 것부터 이어서 한다.
  • train / val / test는 나중에 스크립트로 나눠도 되고, 처음부터 사람별로 나눠 넣어도 된다. 가능하면 test에는 train에 없는 사람 손을 넣는다.
  • 두 명이 라벨링하면 헷갈리는 사진만 서로 확인하고, 자주 갈리는 케이스는 위 표에 추가한다.

5. 촬영 체크리스트

  • 패드 빨간 테두리 네 변이 다 프레임에 들어왔다
  • 손가락 끝이 선명하다
  • 손은 하나만 찍혔다
  • foul의 절반 정도는 "살짝 걸침" 같은 어려운 컷이다
  • normal 중에도 테두리에 바짝 붙은 컷이 섞여 있다 (패드 한가운데만 찍지 않기)
  • 사람·조명·소매·손 방향을 바꿔가며 찍었다
  • 같은 자세 연사는 한 장만 남겼다

6. 자주 하는 실수

  • 팔뚝이 패드 밖이라고 foul 주기 → 팔은 안 본다.
  • 패드 가장자리에 붙어 있다고 foul 주기 → 안에만 있으면 normal.
  • 애매한 걸 대충 한쪽에 넣기 → 뺀다.
